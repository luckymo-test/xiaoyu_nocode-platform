# 视觉质量体系

> 日期：2026-10-25
> 状态：共享视觉方向、视觉系统模板、页面蓝图已完成；审美评审和固定评估待实施

## 一、生成前

所有技术栈共同加载 `prompt/common/visual_direction.txt`，统一约束：

- 信息层级、字体数量、字号层级和正文行宽；
- 色彩比例、材质语言、间距系统与非对称布局；
- 图片的内容作用、构图尺度和裁剪规则；
- 动效边界和 `prefers-reduced-motion`；
- 通用 SaaS 模板感、满屏圆角卡片等必须避免的模式。

## 二、视觉系统模板

模板不再只是文案建议，而是包含：

- 适用区块；
- 色彩、间距、网格、圆角、字号、图片节奏和动效 Token；
- 明确 Art Direction 与视觉记忆点；
- 禁止模式。

当前包含 8 套模板：克制信息型、SaaS 产品叙事、数据控制台、个人作品集、品牌电商、
活动落地页、摄影杂志画廊、品牌编辑故事。全部模板兼容 HTML、多文件、Vue、React 和 Next Profile。

## 三、页面蓝图

代码生成前通过 `PageBlueprintService` 调用规划模型，输出版块、信息任务、布局、密度、
图片用途和比例。蓝图作为后续编码的系统事实注入。

蓝图失败时自动降级为通用视觉 Prompt，不阻塞主生成。开关：

```text
CODEGEN_PAGE_BLUEPRINT_ENABLED=true
```
