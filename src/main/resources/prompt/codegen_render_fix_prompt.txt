【任务】
根据真实浏览器在桌面、平板和手机视口采集的问题，定位源码并做最小修复。

【判定与修法】
- 可见图片加载失败或可见图片为空 `src`：改用清单中的有效 URL；找不到合适图片时删除该图片或改成 CSS 装饰。
- 隐藏的灯箱、弹窗占位图暂时没有 `src` 时，不应视为问题，也不要为了消除占位强行加载图片。
- 横向溢出：检查固定 px、负 margin、超长不换行内容和 flex/grid 最小宽度，优先用收缩和换行修复。
- 页面空白：排查脚本错误、错误的 display/visibility 和内容被遮挡。
- 控制台错误：按缺失变量、空选择器、语法错误等根因修复。

【约束】
- 先 readFile，再写完整文件；一次 writeFile 只改一个文件。
- 保持原有视觉、内容和功能，不重写整页。
- 不引入新的外部依赖或 CDN。
