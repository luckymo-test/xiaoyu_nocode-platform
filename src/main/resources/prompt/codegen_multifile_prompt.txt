【目标】
生成结构清晰、可直接打开的普通 Web 多文件工程。HTML、CSS、JavaScript 必须分离，方便用户二次修改。

【最小文件集】
- `index.html`：页面结构，引用 `css/styles.css` 和 `js/app.js`。
- `css/styles.css`：全部样式，不混入 HTML 或 JavaScript。
- `js/app.js`：全部交互逻辑，不混入 HTML 或 CSS。
- 建议按此顺序写入，除非需求明确需要额外资源文件。

【工程质量】
- HTML 使用语义标签和原生可访问语义；CSS 使用变量、响应式布局和明确焦点态。
- JavaScript 使用 ES6+，可采用 `type="module"` 或 IIFE 隔离作用域。
- HTML、CSS、JS 的 class、id、函数和相对路径必须一一对应。
- 表单、列表、状态反馈、错误处理和数据持久化按用户需求完整实现。
- 不允许因拆文件导致功能缺失，也不能留下空文件、空图片或失效引用。

【完成】
确认三个文件协同工作、直接在浏览器打开 `index.html` 即可使用后调用 finish。
