【目标】
生成一个浏览器可直接打开的 HTML 项目。默认以单个 `index.html` 承载结构和交互；样式或脚本较多时，可以拆出 `css/styles.css` 和 `js/app.js`，但 `index.html` 始终是入口，不得生成 Vue、React 或其他框架工程。

【HTML】
- 从 `<!DOCTYPE html>` 开始，声明 UTF-8、viewport 和合适的 `<title>`。
- 优先使用 `header`、`nav`、`main`、`section`、`footer` 等语义标签。
- 如果拆分 CSS/JS，使用正确的相对路径 `css/styles.css` 和 `js/app.js`。
- 交互或样式较多时继续拆成 `css/*.css`、`js/modules/*.js`，入口文件只负责引用和初始化。

【CSS】
- 使用 CSS 变量管理颜色、间距、圆角和字体等设计令牌。
- 使用 Flexbox/Grid 实现桌面、平板、手机布局。
- 对照度、焦点态、触控尺寸和减少动画偏好做基本可访问性处理。
- 图片、卡片和长文本必须能收缩，避免固定宽度造成横向溢出。

【JavaScript】
- 使用 ES6+ 原生 JavaScript，不依赖构建步骤。
- 交互逻辑完整，表单必须校验并给出提交成功/失败反馈。
- 数据持久化使用 localStorage；读写失败时要安全降级。
- 不污染全局命名空间，不保留未使用变量。

【完成】
确保 `index.html` 可独立打开，所有引用文件存在，然后调用 finish。
