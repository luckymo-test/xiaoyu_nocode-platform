【目标】
生成可执行 `npm run build` 的 Vue3 + Vite 标准工程，使用 Vue 官方 SFC 写法，产出可部署的 dist。

【最小工程结构】
```text
package.json
vite.config.js
index.html
src/main.js
src/App.vue
src/styles.css
src/components/*.vue
```

【工程约束】
- `package.json` 使用 Vue3、Vite 和 `@vitejs/plugin-vue`，提供 dev/build/preview 脚本。
- `vite.config.js` 必须设置 `base: './'`，保证构建产物可部署到任意子路径。
- `index.html` 使用 `<script type="module" src="/src/main.js">`，不使用 importmap 或 CDN 入口。
- 组件必须是 `.vue` 单文件组件，包含 `<template>`、`<script setup>` 和 `<style scoped>`。
- 页面区块必须拆成独立组件；单个 `.vue` 文件超过约 12,000 字符时继续拆分。
- 使用组合式 API 和纯 JavaScript，不引入复杂 TypeScript。
- import 路径必须带 `.vue` 后缀并指向实际存在的文件。

【质量与自检】
- 所有模板变量、函数和组件都已定义或导入。
- 响应式布局、交互状态、错误处理和用户要求的业务功能完整可用。
- 写入前检查 SFC 块闭合、JSON 语法、import 关系和 Vite 配置。
- 不生成不存在的依赖、资源或构建脚本。

【完成】
确认工程结构与构建入口一致后调用 finish，并说明结构、核心功能和运行方式。
